2. For Security :
-----------------

Hashing data cannot be retrieve back but it can validate. It should be always string but not integers.
 It is used :
           1. Werkzeug  --- from werkzug.security import generate_password_hash, check_password_hash
           2. bcrypt   --- import bcrypt

1.Werkzeug  :
       Uses the function called generate_password_hash - Encrypting & check_password_hash - Validating -  syn : check_password_hash(hashed_data,data) .

These are imported from werkzug.secuirty package.

@app.route("/hashing")
def hashing():
    data = "hello1234"
    result = generate_password_hash(data)
    if check_password_hash(result,"hello1234"):
        return "Both Are Same"
    else:
        return "Both Are Not Same"


2. Bcrypt :
           import 
           Uses the functions called : 1. hashpw()
                                       2. checkpw()
                                       3. gensalt() To make hashing, we are creating salt for hashpw and checkpw.

data --> Encode --> bytes --> hashing

--> Data is intially encoded
--> Then salt is generated
--> hashpw() is also generated with data & salt
--> result is validated using checkpw().

@app.route("/hashing2")
def hashing2():
    data = "hello1234"
    data = data.encode()
    salt = bcrypt.gensalt()  # Generating the salt
    result = bcrypt.hashpw(data,salt)
    if bcrypt.checkpw("hello1234".encode(),result):
        return "Both are same"
    else:
        return "Both are not same"

 Cryptography -- Encyption & Decryption : 
 ----------------------------------------
  
Encryption - Plain text to Cypher text
Decryption - Cypher text to Plain text

1. Symmetric : Same keys used for encryp & decryp
2. Asymmetirc : Uses different keys.

### The main difference between hashing and cryptography is 
==> Hashing is onesided -- once created cant retrieve back but can be validated.*** Used for passwords
==> Cryptography is twosided -- It can be encrypted and also decrypted.*** Used for WhatsApp msgs                                                      

Steps :
-------
# step 1: Generating key
# step 2: Convert Data into Bytes
# step 3: Creating object for fernet class using key
# step 4: Encryption from fernet class
# step 5: Decryption from fernet class

@app.route("/encrypt")
def encryption():
    data = "hello1234"
    key = Fernet.generate_key() # step 1: Generating key
    data = data.encode() # step 2: Convert Data into Bytes
    f1 = Fernet(key) # step 3: Creating object for fernet class using key
    encrypted_data = f1.encrypt(data) # step 4: Encryption
    decrypted_data = f1.decrypt(encrypted_data) # step 5: Decryption
    return decrypted_data
